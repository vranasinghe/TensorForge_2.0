About the model

Approach, measured performance and operational detail. Every number below was measured on this project.

Architecture

Word (1–2) and character char_wb (2–6) TF-IDF plus a one-hot channel. The primary is a soft vote of two calibrated LinearSVC members over two tokenisations, fitted on all 4,000 training rows with five-fold out-of-fold calibration, then a temperature of 0.85. Urgency is a separate two-member vote over character 3–6; secondary presence and the secondary label are separate models again.

Security

The evaluation key is read from the API_KEY environment variable and compared in constant time. This page never receives it. The demo sits behind its own credentials and proxies every call server-side, so the key is never in browser JavaScript, an image layer, a log or the release archive. A missing key fails closed with 401.

Human review

The optional needs_human_review flag is confidence < 0.525, the smallest cut that reaches 80% accuracy on auto-routed tickets. On held-out rows it flags 34% of tickets; the auto-routed remainder is right 80.3% of the time, against 33.1% for the flagged slice.
